# Tomarigi規則のNEXUS移植棚卸し

## 方針

MeCab 0.996・CRF++ 0.58・CaboCha 0.69のMacネイティブ解析環境は、
Tomarigi本来の解析結果を比較する参照実装として保持する。一方、Tomarigi本体の
Windows Forms・古い.NETプラグイン・画面互換をNEXUSの実行経路へ組み込むことはしない。
校正規則はNEXUSのtextlint層へ、誤検出を抑えた独立規則として移植する。

判定は次の3分類とする。

- **既存**：NEXUSに同等機能がある。新しい重複実装は作らない。
- **候補**：価値があり、入力と出力を独立テストできるもの。小さく追加する。
- **保留／対象外**：文脈依存が強い、元プラグインの状態に依存する、またはMac互換層を必要とするもの。

## 実装順

1. 候補のうち、入力範囲と指摘位置が決定的なものを1規則ずつ追加する。
2. 各規則に「正常例」「指摘例」「固有名詞・作品固有語の除外例」を置く。
3. 自動修正は表記辞書系だけに限定し、文体・意味判断系は通知のみとする。
4. `t_revisepoorsentence`のような複合プラグインは再実装せず、必要な小規則だけを抽出する。
5. Macネイティブ解析環境は参照・比較用に保持するが、`Tomarigi3.exe`、Windows用DLL、Mono互換層はNEXUS実行経路に組み込まない。

## 重要な境界

この棚卸しでの「既存」は、Tomarigi本体と同じ判定結果になるという意味ではない。
NEXUSの現在の校正層で、より安全な入力範囲と明示的なテストを持っているという意味である。
Tomarigiの本来の解析結果とNEXUS側の安全化した規則は別結果として扱い、後者はUI上も「Tomarigi相当」と表示する。
